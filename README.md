# Python Data Analysis & APIs

## Overview

This project is a Python-based Student Performance Data Analysis application developed as part of Module 4 – Python Data & APIs.

The project demonstrates data loading, cleaning, manipulation, statistical analysis, visualization, REST API consumption, JSON processing, and report generation.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Requests
- REST API
- JSON

## Project Features

- Load student data from a CSV file
- Clean and preprocess data
- Handle missing values
- Remove duplicate records
- Calculate statistical values
- Analyze student performance
- Perform department-wise analysis
- Create data visualizations
- Consume a REST API
- Process JSON responses
- Generate an analysis report

## Data Analysis

The application calculates:

- Total number of students
- Average marks
- Highest marks
- Lowest marks
- Average attendance
- Top-performing student
- Department-wise average marks

## Visualizations

The project uses Matplotlib and Seaborn to create:

- Student performance bar chart
- Study hours vs marks scatter plot
- Department-wise performance analysis
- Correlation analysis

## REST API

The project also demonstrates consuming a REST API using Python's `requests` library.

The API response is received in JSON format and processed using Python and Pandas.

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python analysis.py
```
